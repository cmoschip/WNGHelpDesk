Logo Placement Instructions
============================

Place your WN Global company logo in this directory with the filename:
wn-global-logo.png

The logo will appear in:
1. The top navigation bar (navbar) - displayed at 32px height
2. All email notifications - displayed at 180px width

Recommended logo specifications:
- Format: PNG with transparent background
- Dimensions: At least 400px wide for best quality
- Aspect ratio: Horizontal/landscape orientation works best

After placing the logo file here, restart the IIS application pool or run iisreset for the changes to take effect.
